## 本地看

纯静态 HTML，没有构建步骤，也没有外部依赖。浏览器打开 `index.html` 就能读——站点用相对路径，直接开 `file://` 也行，只是配色选择靠 localStorage 记住，`file://` 下部分浏览器不保存。想更接近线上效果，在仓库根目录起个静态服务器：

```
python3 -m http.server 8000
```

然后开 <http://localhost:8000/>。

## 数据来源

名词以游戏本体数据文件的中文本地化文本为准；具体数字来自社区实测整理页，主要是 [Starside](https://starside.work/index.html)；部分数值与英文原始表交叉核对。各页脚注写明该节引用的具体来源。

写法上正文只用官方译名，第一次出现时用括号给出玩家俗称（如「威能武器（重弹）」），之后只用官方名。完整对照见 `机制教程/terms.html` 第 6 节。

数值会随赛季变化。手册讲的是规则和关系（比如同类取最高、跨类相乘），具体数字以来源页面当期内容为准；正文里标了「查表」徽章的表都带数据日期。
